# Portfolio — Amadou Niane

Portfolio personnel statique, prêt à être publié avec **GitHub Pages**.

## 1. Personnalisation indispensable
Dans `index.html`, remplace :
- `VOTRE_EMAIL` par ton adresse e-mail ;
- `VOTRE-PSEUDO` par ton identifiant GitHub ;
- `VOTRE-PROFIL` par ton identifiant LinkedIn.

Vérifie aussi les descriptions des projets, les formations et les compétences pour qu'elles correspondent exactement à ton niveau actuel. La partie Linux est volontairement présentée comme une formation en cours, pas comme une expertise déjà acquise.

Tu peux ajouter une photo professionnelle dans le dossier et remplacer le bloc terminal de la page d'accueil si tu le souhaites.

## 2. Publier gratuitement sur GitHub Pages
1. Crée un compte sur https://github.com si tu n'en as pas.
2. Crée un nouveau dépôt public nommé `amadou-niane.github.io` (remplace `amadou-niane` par ton pseudo GitHub).
3. Décompresse ce dossier sur ton ordinateur.
4. Envoie `index.html`, `style.css`, `script.js` et `README.md` à la racine du dépôt.
5. Dans le dépôt, ouvre **Settings → Pages**.
6. Dans **Build and deployment**, choisis **Deploy from a branch**, puis `main` et `/ (root)`, et enregistre.
7. Après quelques minutes, le site sera disponible à `https://TON-PSEUDO.github.io`.

## 3. Structure
- `index.html` : contenu et sections du portfolio.
- `style.css` : design responsive.
- `script.js` : menu mobile.

## 4. À compléter avant de le partager
- Ajouter tes vrais liens GitHub et LinkedIn.
- Vérifier les dates exactes de ton parcours.
- Ajouter des captures d'écran et des dépôts GitHub pour MonLocal, CleanAll et tes travaux réseau.
- Ajouter progressivement des preuves de tes apprentissages Linux : commandes pratiquées, scripts, utilisateurs/groupes, permissions, services, réseau et documentation.
